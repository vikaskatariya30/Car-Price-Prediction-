# 🚗 Car Price Predictor

A machine learning project that predicts the resale price of a used car from its brand, model, age, kilometres driven, fuel type, seller type, transmission and ownership history. It ships with a **Streamlit** web app for live predictions, and includes a notebook for a simple **content-based car recommender**.

## Features

- Predicts used-car prices in INR through an interactive Streamlit UI
- Compares 8 regression models and deploys the best one (XGBoost, R² ≈ 0.91)
- Single scikit-learn `Pipeline` (encoding + model) saved as `model.pkl`
- Bonus: car recommender using text tags, price and cosine similarity

## Tech Stack

Python · pandas · NumPy · scikit-learn · XGBoost · NLTK · Seaborn / Matplotlib · Streamlit

## Dataset

Used-car listings from CarDekho (8,128 rows). After cleaning, the columns used are:

| Column | Description |
|---|---|
| `name` | Car name (first three words of the listing) |
| `company` | Brand, derived from `name` |
| `year` | Year of manufacture |
| `km_driven` | Kilometres driven |
| `fuel` | Petrol, Diesel, CNG, LPG, Electric |
| `seller_type` | Individual, Dealer, Trustmark Dealer |
| `transmission` | Manual or Automatic |
| `owner` | First, Second, Third, Fourth & Above, Test Drive |
| `selling_price` | **Target** (INR) |

## Methodology

1. **Cleaning:** shortened `name` to its first three words, extracted `company`, and dropped `mileage`, `engine`, `max_power` and `seats` (they contain missing values).
2. **Preprocessing:** `OneHotEncoder(drop='first', handle_unknown='ignore')` on categorical columns via `ColumnTransformer`, with numeric columns passed through.
3. **Modelling:** 8 regressors compared on an 80/20 train/test split.
4. **Deployment:** the best model is wrapped in a `Pipeline` and pickled.

### Model comparison (R² on test set)

| Model | R² |
|---|---|
| **XGBoost** | **0.912** |
| Lasso | 0.897 |
| Random Forest | 0.843 |
| Linear Regression | 0.811 |
| Decision Tree | 0.780 |
| ElasticNet | 0.592 |
| Ridge | 0.173 |
| SVR | -0.064 |

Scores come from a single random split (no fixed seed on the split), so they will vary slightly between runs.

## Usage

1. Choose the brand and type the car name (e.g. `Maruti Swift Dzire`).
2. Select year, fuel type, seller type, transmission and owner type.
3. Enter the kilometres driven.
4. Click **Predict Price**.

For best results, use car names in the same format as the dataset (see `cleaned_car.csv`), since the model has only seen those names.

## Car Recommender (Notebook)

`recommend_model_training.ipynb` builds a content-based recommender:

- Removes duplicates and missing values (6,718 cars remain)
- Builds a text `tags` field from name, fuel and transmission, then lowercases and stems it with NLTK's Porter stemmer
- Vectorises tags with `CountVectorizer` and appends a `MinMaxScaler`-scaled price
- Computes a cosine-similarity matrix and returns the 5 most similar cars

```python
recommend('Skoda Rapid 1.5')
# Skoda Rapid Ultima, Skoda Octavia Ambiente, Skoda Rapid 1.6, ...
```
